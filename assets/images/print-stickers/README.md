# 印刷质感贴纸

## 1. 素材来源与对应关系

基于用户提供的三张 SVG，保留原始尺寸 212 × 103、原始轮廓与基础配色，桌面原文件未改动。

- `Group 632645-print.svg`：红底。
- `Group 632646-print.svg`：橄榄绿底。
- `Group 632647-print.svg`：奶油色底。

## 2. 独立折痕与套色偏移

使用 SVG 原生滤镜叠加细纸纹和少量油墨露底；油墨边缘有极轻微不规则，各色版按不同方向偏移约 0.4–0.8 个 SVG 单位，并在反方向保留 27% 浓度的薄墨边缘。透明背景保留。每张分别添加独立折痕：红底为右侧斜纵折，绿底为左侧反向斜折，奶油底为横向斜折；各自搭配不同位置的短折痕。

滤镜为独立定义，可继续调整透明度、颗粒频率、位移与折痕强度。SVG 的文字及图形仍是原始矢量路径，无外部素材依赖；导入不支持 SVG 滤镜的软件时可能需要先栅格化。

## 3. 手机高清输出

mobile 目录中的 sticker-632645@4x.png、sticker-632646@4x.png、sticker-632647@4x.png 为对应 SVG 的 4 倍原始尺寸（848 × 412）透明 PNG。通过浏览器原生 SVG 渲染、Canvas PNG 编码确定性导出，未使用生成式改图；导出时将 SVG 根元素 width / height 设为 848 / 412，保留 viewBox、路径、滤镜、折痕及配色。

600px 及以下由 picture/source 选用 PNG，避免 Safari 在小尺寸下实时栅格化滤镜导致模糊；桌面继续加载 SVG。改动 SVG 后同步重新导出 PNG。路径集中在 scripts/siteConfig.js，HTML 包含初始化路径。

## 4. 使用与预览

`preview.png` 为浏览器渲染的质感版 / 原图 / 原始尺寸对比。三张已接入网站：红色页面使用奶油贴纸，奶油页面使用绿色贴纸，绿色页面使用红色贴纸。贴纸与主题同步进行 360ms 交叉渐变。
